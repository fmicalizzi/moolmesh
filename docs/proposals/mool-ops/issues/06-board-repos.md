# "Board" repos (issues-only backlogs)

## Context
Some repos are used only as issue backlogs, with no code. Today they look like projects with no measurable delivery.

## Proposal
Per-repo `kind = "board"`: skip git, and have Project Pulse and an MCP tool list issues filterable by label, assignee and age, with opened/closed counts in a window.

## Acceptance
A repo marked as board shows its backlog by label and is not reported as "no delivery".
